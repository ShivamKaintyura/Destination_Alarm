Questions

Straight answers.

Will it ring if my phone is on silent?

Yes. The tone plays on Android’s alarm audio stream and the app raises alarm volume to 90% while ringing. On Do Not Disturb, allow “Alarms” in the DND settings so the system doesn’t block it.

Does it work on iPhone?

No. iOS does not let third-party apps run background location indefinitely or bypass the silent switch. This is an Android app — Android 8.0 or newer.

Do I need internet while the alarm is armed?

For search and the initial route, yes. Once armed, distance tracking and the alarm itself work offline. If the route can’t be fetched, the GPS geofence still fires normally.

How much battery does it use?

Tracking uses GPS continuously, so expect a few percent per hour. For long journeys, plug in — the app is designed to run for hours with the screen off.

My Xiaomi / Oppo / Vivo kills the app. What now?

Open the app’s battery settings and allow Autostart plus “No restrictions”. On MIUI also lock the app in the recent-apps screen. This is an OEM restriction, not an app bug.

Is it really free? Where’s the map from?

Free, no ads, no account. Maps come from OpenFreeMap, search from Photon + Nominatim, routing from OSRM — all OpenStreetMap-based. No Google Maps billing, no API key.

Is the APK safe to install?

It’s signed with a debug key for direct installation, so Android will ask you to allow “Install unknown apps” for your browser. A Play Store build is the next step; until then, download only from this page.
